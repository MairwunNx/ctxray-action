# ctxray action

[ctxray](https://github.com/MairwunNx/ctxray) shows what Claude Code, Codex, Cursor, Gemini CLI, and OpenCode load into a model's context, and tests it in CI. This action installs ctxray and runs `ctxray test`.

The action arrives with ctxray's first release. Issues and changes go to [MairwunNx/ctxray](https://github.com/MairwunNx/ctxray).
